# Prototipos DJPlus UI

Este directorio contiene prototipos visuales autónomos para la rama `release/v1.0.0-visual-polish`.

## Prototipos

- `library/`
  - `index.html`
  - `styles.css`
  - `README.md`
  - Prototipo de la pantalla de Biblioteca, con navegación lateral compacta, buscador, filtros, vista de portadas y Preview Player fijo inferior.

- `playlist/`
  - `index.html`
  - `styles.css`
  - `README.md`
  - Prototipo de Playlist, con curva de energía superior, tabla/lista de tracks, selección clara y Preview Player fijo inferior.

- `dj-set/`
  - `index.html`
  - `styles.css`
  - `README.md`
  - Prototipo de DJ Set, con viaje de energía completo, capítulos, curva objetivo opcional y Preview Player fijo inferior.

## Cómo ejecutar

Abrir el archivo `index.html` correspondiente en un navegador moderno:

- `docs/ui/prototypes/library/index.html`
- `docs/ui/prototypes/playlist/index.html`
- `docs/ui/prototypes/dj-set/index.html`

Todos los prototipos usan HTML, CSS y JavaScript locales sin dependencias externas.
