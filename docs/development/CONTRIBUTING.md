# Contributing

## Flujo de contribución

1. Revisar arquitectura, roadmap y alcance aprobado.
2. Trabajar en un único objetivo verificable.
3. Añadir o actualizar pruebas y documentación relacionadas.
4. Validar arranque, consultas o comportamiento afectado.
5. Solicitar revisión antes de cambios de arquitectura o movimientos masivos.
6. Crear un commit claro cuando el hito esté completo y aprobado.

## Límites de cambios

No introducir IA, plugins, sincronización, análisis musical ni integraciones externas sin un sprint aprobado que defina contratos, seguridad y pruebas.
