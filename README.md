# DJPlus

DJPlus es una base inicial para una biblioteca musical orientada a DJs.

## Estructura inicial

- app/main.py: punto de entrada de la aplicación
- app/database.py: configuración de la base de datos SQLite
- app/models.py: modelos de datos para pistas
- app/scanner.py: escaneo básico de archivos musicales

## Requisitos

```bash
pip install -r requirements.txt
```

## Uso

```bash
python -m app.main
```
